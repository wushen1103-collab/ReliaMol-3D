# Curated Paper Results

This folder contains small derived tables copied from the remote experiment output reports. It is included so readers can verify manuscript-level numbers without downloading or committing multi-GB raw molecular data.

Included:

- compact CSV, JSON, and Markdown summaries from `outputs/*/reports/`;
- receptor-coordinate provenance summaries;
- main reranking, ablation, calibration, sensitivity, PoseBusters, docking baseline, TargetDiff-family, and DUD-E stress-test summaries.

Excluded:

- raw generated SDF/MOL2/PT files;
- raw receptor or docking work directories;
- feature frames and large candidate audit tables;
- per-candidate prediction tables;
- figures and manuscript PDFs.

Use `docs/paper_result_map.md` to connect these files to manuscript tables and claims.
